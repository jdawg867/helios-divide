# Helios Divide

**One system. No common ground.**

Helios Divide is an original hard-science-fiction first/third-person shooter RPG set in a politically fractured, colonized Solar System.

The project begins with a focused vertical slice called **Dead Freight**:

- Seamless first/third-person switching
- Tactical firearms combat
- Zero-G and EVA traversal
- Magnetic boots and suit thrusters
- Dialogue and quest choices
- Faction reputation
- A player-owned spacecraft
- Companion gameplay
- A grounded political science-fiction setting

## IP

Helios Divide is an original game universe. It may draw inspiration from broad hard-science-fiction genre concepts, but its characters, factions, story, terminology, visual identity, and assets are original.
